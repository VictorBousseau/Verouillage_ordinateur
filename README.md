# Blague de Verrouillage PC 🔐

Un petit site web pour piéger les collègues qui laissent leur ordinateur déverrouillé !

## Comment l'utiliser ?
1. Ouvrez le site.
2. Mettez le navigateur en plein écran.
3. Attendez que votre collègue revienne...
4. Quand il clique ou appuie sur une touche : **SURPRISE !**
5. Choisissez sa punition (Croissants, Pizza, etc.).

## Fonctionnalités
- Faux écran bleu (BSOD) réaliste
- Révélation avec confettis
- Choix de punitions variées
